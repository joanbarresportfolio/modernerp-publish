# ModernERP: publicaciones

Vídeos e imágenes de ModernERP para las redes sociales. Este repositorio es **público** a propósito: Metricool descarga cada archivo desde su enlace público (`raw.githubusercontent.com`) para publicarlo en Instagram, Facebook y YouTube.

## Normas

- Solo material que se va a publicar. Nada de datos de clientes, empleados ni proveedores reales: las capturas, siempre de la empresa de demostración.
- Sin claves, contraseñas ni documentos internos. La documentación y los guiones están en el repositorio privado `modern-software` (`docs/marketing/`).
- Sin emoticonos.
- Lo lleva MARKETING; la programación en Metricool, MARKETING u OPERACIONES.

## Estructura

```
media/AAAA-MM/AAAA-MM-DD-nombre-corto.mp4   vídeos verticales 1080x1920
media/AAAA-MM/AAAA-MM-DD-nombre-corto-1.png carruseles e imágenes (1080x1350 o 1080x1080)
```

Enlace público de cada archivo:

`https://raw.githubusercontent.com/joanbarresportfolio/modernerp-publish/main/media/AAAA-MM/<archivo>`

Los archivos ya publicados no se borran ni se cambian de nombre, para que los enlaces sigan funcionando.
